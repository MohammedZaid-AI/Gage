PART 3 - Local number check (works without Groq)

New backend/ai/number_check.py, merged into claim_check.check (one caveat):
- numbers with units vs. ALL retrieved chunks + question + farm readings/alerts;
  normalised: mm/cm/m, %, kg/q/t, days/weeks/months, ₹/Rs, °C; Kannada digits and
  units (ಸೆಂ.ಮೀ, ದಿನ ...); written numbers (two weeks); ranges 7-8 / 7–8 / 7 to 8 / 7 ರಿಂದ 8.
- inputs never named in the sources; inputs tied to a purpose (gypsum -> iron) that no
  source paragraph ties them to (aliases: FYM = farm yard manure, FeSO4 = ferrous sulphate).
- farm readings called low/high/optimal/adequate with no range in that unit in the text.
- name check kept. Groq findings that repeat a locally flagged number are not listed twice.
- Groq skipped/unavailable -> note "only the local number and name checks ran".
